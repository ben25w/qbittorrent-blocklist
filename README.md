# qbittorrent-blocklist

An IP blocklist for qBittorrent in PeerGuardian `.p2p` format (one `Name:start-end` range per line).

In qBittorrent, go to Options > Connection > "Filter path (.dat, .p2p, .p2b)" and paste:

```
https://raw.githubusercontent.com/ben25w/qbittorrent-blocklist/main/blocklist.p2p
```
